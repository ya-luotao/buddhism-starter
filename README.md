## 研究与训练

佛学是研究：历史、文本、义理，目标是弄清楚它在说什么。学佛是训练：每日静坐，目标是改变知觉方式。两者都需要，但应当清楚自己在做哪一件。只读不练，容易把佛教当成一套可以读完的哲学，读完之后苦并没有变化。只练不读，则没有地图，容易把某个阶段当成终点，或把路上的低谷当成失败。

理解并不能到达苦产生的层面。一个人可以完全接受无我的论证，自我感并不因此改变，正如知道缪勒-莱耶错觉是错觉，两条线看起来仍然不一样长。佛教从一开始就区分了这两件事：闻慧、思慧、修慧是三个层次，正见只是八正道的第一支。它提供的是训练，而不只是理论。

## 从悉达多的经历开始

佛教的核心教义大多能在佛陀自己的经历中找到来源，从生平进入，比从教义条目进入更容易理解为什么是这几条。需要先说明：关于他的生平，史料能确认的只是一个骨架，四门出游之类的细节出自后来的传记。传说的部分仍有参考价值，它反映了后人认为哪些事最重要。

他大约生于公元前五世纪，今尼泊尔与印度边境一带，释迦族一个小城邦的贵族家庭。传记记载他在优渥的环境中长大，二十九岁出城见到老人、病人、死者和出家人，意识到财富无法阻止前三件事，于是离家。史料能确认的是，他确实在青年时期离开家庭成为沙门，这在当时的印度是一种并不罕见的选择。

他先后师从阿罗逻迦兰和郁陀迦罗摩子，学到了当时最深的禅定，两位老师都邀请他留下共同领导教团。他离开了，理由是这些状态无论多深都会退出，退出之后苦仍然存在。这是佛教不以禅定状态为目标这一原则的来源。随后他转向另一个极端，苦行六年，经典记载他绝食到能从腹部触到脊柱，结论是这条路同样不通。他接受了村女供养的乳粥，一同苦行的五位同伴认为他放弃了修行，离他而去。这一段是中道的来源：纵欲与自苦都已尝试，两端都无效。

三十五岁，他在一棵树下静坐，传记称他立誓不证悟不起座。那一夜发生了什么，经典用他后来的教法来描述：见缘起，见苦如何生起、如何止息。此后他曾犹豫是否要教人，认为这件事逆于常人的习惯，难以被理解，传记称是梵天劝请之后他才决定说法。他找到离开他的五位同伴，在鹿野苑初次说法，内容是四圣谛与八正道，即[《转法轮经》](https://suttacentral.net/sn56.11/zh/zhuang)。

此后四十五年，他在恒河平原游行教化，建立僧团，回答了大量问题，也拒绝回答了一些，例如世界是否有边、证悟者死后是否存在。他的理由是这些问题不导向苦的止息，如同中毒箭的人坚持先弄清射箭者是谁才肯拔箭。八十岁时他因饮食致病，在拘尸那罗的树林中去世。临终前弟子问此后以谁为师，他回答以法为师、以自己为依靠，没有指定继承人。经典记载的最后一句话是：一切有条件的事物都会坏灭，应当不放逸地努力。

从这段经历可以看出佛教的几个特点：它始于一个具体的人的困境，而不是启示；创立者自称只是重新发现了一条旧路；方法是在两次失败之后才找到的；它回避形而上学问题；它不设立最高权威。后来的历史中，这几点都曾被不同程度地背离。

## 常见误解和实际情况

| 常见说法 | 实际情况 |
|---|---|
| 佛是神，拜佛可以获得保佑 | 佛是称号，梵语 buddha，意为觉醒者。释迦牟尼是历史人物，生活在公元前五世纪前后。早期经典中他明确否认自己是神或天人。他死后的状态，是他拒绝回答的问题之一。 |
| 烧香、许愿、还愿是佛教的核心 | 这是在家信众积累功德的层面，佛陀时代已有，但从来不是目标。交易式的许愿还愿，是中国民间信仰的模式套用在佛教人物上。 |
| 佛教消极，否定人生 | 佛陀初次说法就排除了两个极端：沉溺欲乐与自我折磨。他反对的是渴爱和执取，不是欲望本身，更不是生活。 |
| 一切皆空即什么都不存在 | 空指无自性：任何事物都不能脱离条件独立存在，包括自我。它否定的是独立实体，不否定现象。[《中论》](https://cbetaonline.dila.edu.tw/zh/T1564)明确反对把空理解为虚无。 |
| 开悟是一种永恒的极乐状态 | 各传统所说的开悟是知觉方式的转变：自我模型从透明变为可见，被认出是一个模型。日常功能照常，并非持续处于特殊状态。它分阶段，第一次转变之后苦仍存在，减少的是对苦的抗拒。 |
| 冥想就是放空、什么都不想 | 佛教的观是看清楚。走神之后注意到，回到对象，这个动作本身就是练习。追求心中一片空白，传统上被视为一种偏差。 |
| 佛教就是禅，禅就是心灵读物 | 禅宗是汉传佛教的一个宗派，建立在数百年的早期佛教和中观之上。脱离这一基础读禅宗语录，容易只读到风格。 |
| 佛教是科学，或者佛教早已发现量子力学 | 都不是。佛教是关于苦和自我的现象学与训练，它对世界的描述沿用了当时印度的预设。把佛教表述为科学，是二十世纪以来的现代主义叙事。 |
| 轮回是佛教的发现 | 轮回是佛陀时代印度的普遍观念，佛教继承并改造了它。它在早期文本中是承重结构，但初学者可以先把它搁置。 |
| 学佛必须吃素 | 早期僧团托钵，施主给什么吃什么。汉传僧人的全面素食始于六世纪梁武帝的推动。南传和藏传僧人不要求素食，在家人更无此要求。 |
| 学佛必须皈依、去寺庙、拜师 | 皈依是正式表明方向，不是入会。读和练都不以皈依为前提。老师和共修在某个阶段很重要，目的是防止练习走偏，不是资格。 |
| 佛教反对思考，只要求信 | 早期经典中佛陀要求听者自行检验，[《卡拉玛经》](https://suttacentral.net/an3.65/zh/zhuang)是最常被引用的段落。信在五根中列第一位，但那是任何训练都需要的信任：先按说明去做尚不能验证的事。 |

## 核心义理

佛陀把自己比作医生，四圣谛就是诊断的格式：病、病因、痊愈的可能、处方。

**苦。** 巴利语 dukkha，译作苦偏重，更接近不满足、不安稳、不可靠。三种：明显的痛苦；变化带来的失去；最细的一种，一切构造物本身的不稳定。佛教不主张人生全是痛苦，它主张任何依靠抓取来维持的东西最终不可靠。

**集。** 苦的原因是渴爱与执取。不是欲望，而是非如此不可、非我莫属的抓取，其中最核心的对象是"我"。

**灭。** 抓取可以止息，止息之后苦也止息。这一状态称为涅槃，字面意义是熄灭，熄灭的是贪、嗔、痴。它不是死亡，不是天堂，也不是虚无。被问到证悟者死后是否存在时，佛陀拒绝回答，认为这个问题的提法本身有误。

**道。** 处方是八正道，分三组：慧（正见、正思维）、戒（正语、正业、正命）、定（正精进、正念、正定）。它是一套训练。正见排在第一，但只是第一步。

三法印。诸行无常：一切有条件的事物都在变化。诸法无我：任何事物中都找不到独立、恒常的核心，包括自我。第三项上座部作苦，汉传作涅槃寂静。

缘起。此有故彼有，此生故彼生。一切事物都是条件的产物，没有条件之外独立存在的东西。这是无我和空的基础。

五蕴。佛教把人分析为五类：色是身体，受是感受的基调，想是识别，行是意志与习惯，识是意识。逐一审视，每一类都在变化，每一类都不是"我"，也找不到五蕴之外的持有者。无我是这一分析的结论，练习就是在直接经验中反复进行这一分析。出处见[《无我相经》](https://suttacentral.net/sn22.59/zh/zhuang)。

二箭。第一支箭是痛。第二支箭是对痛的抗拒、"为什么是我"、想要逃离。修行者同样会中第一支箭，修行去除的是第二支。这是对佛教实际承诺的较准确概括，出处见[《箭经》](https://suttacentral.net/sn36.6/zh/zhuang)，相应部 36.6。

方便。教法按听者的根器调整，同一件事对不同的人有不同说法。这解释了佛教内部说法为何差异很大，也解释了求福信仰的来源：较低的阶梯本是通向上层的，后来阶梯本身成了全部。

## 求福信仰的形成

求福的层面从一开始就存在，后来的历史摧毁了它旁边的训练层面，它才单独留了下来。这一节以中国的情况为主。

出家与在家从一开始就是两种不同的实践。出家人修出世间法，目标是涅槃。在家人的功课是布施、持戒、积功德，目标是今生顺利与来世更好。佛陀亲自为在家人讲理财、家庭和往生善趣，这一层面是他自己设计的，只是从未被当作终点。在家人始终是绝大多数。

佛陀去世后留下真空。舍利被分配，佛塔建立，绕塔与供养成为在家人最主要的实践。佛像到公元一世纪前后才出现，此前只以足印、法轮、菩提树作为象征，因为当时认为他已不在任何地方。

大乘把祈求写入经典。《法华经·普门品》说称念观音名号可免火难水难，净土经典中阿弥陀佛发愿，称念其名号者可往生极乐。背后是方便这一自觉的设计：教法按根器调整，较低的阶梯也通向上层。风险也在同一处：阶梯可能成为全部。

传入中国后，佛教被套入另一套模式。中国原有祖先祭祀、官僚化的冥界和向神祇许愿还愿的交易模式，佛教与之合流：盂兰盆节用于超度祖先，地藏成为冥界主宰，十殿阎罗是中国本土形成的观念，观音在宋以后逐渐女性化并吸收了地方女神，弥勒的形象被五代的布袋和尚取代。烧香本身是印度的供养方式，但烧纸钱、许愿还愿、把佛菩萨视为可以馈赠疏通的官员，这一框架来自中国民间信仰。

义理传承曾被物理摧毁。845 年会昌灭佛，寺院被拆，经卷散失，依赖大量典籍的唯识、华严、天台从此衰落。存续下来的是两个几乎不需要基础设施的宗派：禅宗不依赖经典，净土只需一句名号。宋以后禅净合流，明清以后寺院的经济基础转为经忏，即有偿的法事和超度。太虚在 1920 年代批评当时的佛教偏重度亡与祭鬼，提出人间佛教，今天台湾的几个大型教团都出自这一脉络。

二十世纪再次中断。1949 年后中国大陆寺院大多关闭，僧团教育停止；八十年代恢复宗教活动后，首先重建的是寺院建筑和香火，禅修训练的师承恢复得最慢。

因此今天多数人看到的，是在家层面加民间信仰模式加旅游经济，而原本与之并存的训练层面损失最重。这并非佛教独有，基督教从登山宝训到赎罪券的变化属于同一类过程。多数信众需要的是现实生活中的帮助，供给随之调整。

## 传承地图

三条主要传承：

| 传承 | 地区 | 经典语言 | 特点 | 练习方法 |
|---|---|---|---|---|
| 上座部（南传） | 斯里兰卡、泰国、缅甸、柬埔寨、老挝 | 巴利语 | 最接近早期佛教的形态，义理保守，阶段地图最清楚 | 止禅、内观（马哈希、葛印卡、泰国森林传统等） |
| 大乘（汉传） | 中国、日本、韩国、越南 | 汉语，译自梵语 | 菩萨道，空与佛性，宗派多 | 禅（坐禅、公案）、念佛、止观 |
| 金刚乘（藏传） | 西藏、蒙古、不丹、尼泊尔 | 藏语 | 在大乘之上加密续，强调上师和传承 | 前行、本尊、大手印、大圆满 |

汉传的主要宗派：

| 宗派 | 一句话 | 代表经典 |
|---|---|---|
| 禅宗 | 直指人心，不立文字，坐禅或参公案 | 《坛经》《临济录》《无门关》《碧岩录》 |
| 净土宗 | 念阿弥陀佛名号，求生极乐世界，再在那里修行 | 《阿弥陀经》《无量寿经》《观无量寿经》 |
| 天台宗 | 判教体系加止观实修 | 《法华经》《摩诃止观》 |
| 华严宗 | 法界缘起，事事无碍，体系最宏大的形而上学 | 《华严经》 |
| 唯识宗 | 万法唯识，八识三性，最精细的心理学 | 《唯识三十颂》《成唯识论》《解深密经》 |
| 三论宗 | 中观，空 | 《中论》《百论》《十二门论》 |
| 律宗 | 戒律的研究和实践 | 《四分律》 |

这份指引偏向早期佛教的义理和上座部、禅宗的练习方法。对藏传和净土说得少，原因是作者不熟悉，而且藏传的入门条件（上师、传承、灌顶）对本指引的读者是额外的一层。

## 阅读路线

建议从早期佛教开始，不从禅宗开始。禅宗文本短而精炼，但没有早期佛教作为基础，容易只读到风格。后来的一切都是对早期层面的注释。顺序如下，每一步给出中英文选项，选一本即可。

**第一步，概论。**

- 印顺[《佛法概论》](https://cbetaonline.dila.edu.tw/zh/Y0008)。中文世界最系统的入门之一，历史批判的方法，区分早期与后起的内容。全文在 CBETA 免费。
- 圣严《正信的佛教》《学佛群疑》。针对中文读者常见误解写的问答体著作，篇幅短。全文在[法鼓全集](https://ddc.shengyen.org/)佛教入门类下免费。
- Walpola Rahula [*What the Buddha Taught*](https://en.wikipedia.org/wiki/What_the_Buddha_Taught)，中译《佛陀的启示》。上座部视角，一百余页。
- [Rupert Gethin](https://en.wikipedia.org/wiki/Rupert_Gethin) *The Foundations of Buddhism*。学术著作，覆盖三大传承。

**第二步，早期经典。** 这一层面最接近心理学，形而上学成分最少。

- [菩提比丘](https://en.wikipedia.org/wiki/Bhikkhu_Bodhi)编 *In the Buddha's Words*。巴利经藏按主题编选，每章有导读。
- [《法句经》](https://suttacentral.net/dhp)。篇幅短。汉译见 [CBETA](https://cbetaonline.dila.edu.tw/zh/T0210)。
- 原典可直接读 [SuttaCentral](https://suttacentral.net/)，庄春江译的尼柯耶与汉译阿含可对照。建议先读[《转法轮经》](https://suttacentral.net/sn56.11/zh/zhuang)、[《无我相经》](https://suttacentral.net/sn22.59/zh/zhuang)、[《念处经》](https://suttacentral.net/mn10/zh/zhuang)、[《安那般那念经》](https://suttacentral.net/mn118/zh/zhuang)、[《卡拉玛经》](https://suttacentral.net/an3.65/zh/zhuang)、[《箭经》](https://suttacentral.net/sn36.6/zh/zhuang)。

**第三步，中观。** 空的确切含义。

- [《中论》](https://cbetaonline.dila.edu.tw/zh/T1564)，配印顺[《中观论颂讲记》](https://cbetaonline.dila.edu.tw/zh/Y0005)，或 Jay Garfield *The Fundamental Wisdom of the Middle Way*。Garfield 出身分析哲学，逐颂注释，适合习惯论证的读者。Siderits 与 Katsura 的译本更严格。各英译本见[维基百科条目](https://en.wikipedia.org/wiki/M%C5%ABlamadhyamakak%C4%81rik%C4%81)。

**第四步，禅宗。** 有了前面的基础，才能看出禅宗是在用另一种语法表达同样的内容。

- [《六祖坛经》](https://cbetaonline.dila.edu.tw/zh/T2008)。篇幅短，可读原文。
- [《临济录》](https://cbetaonline.dila.edu.tw/zh/T1985)、[《无门关》](https://cbetaonline.dila.edu.tw/zh/T2005)。
- 铃木俊隆[《禅者的初心》](https://en.wikipedia.org/wiki/Zen_Mind,_Beginner%27s_Mind)。讲练习的态度。
- 印顺[《中国禅宗史》](https://cbetaonline.dila.edu.tw/zh/Y0038)。区分禅宗的史实与传说。

**第五步，现代批判与旁证。**

- Evan Thompson [*Why I Am Not a Buddhist*](https://yalebooks.yale.edu/book/9780300226553/why-i-am-not-a-buddhist/)。批评"佛教即科学"的现代主义叙事。作者研究佛教哲学与认知科学，批评来自内部。
- [平川彰](https://zh.wikipedia.org/wiki/%E5%B9%B3%E5%B7%9D%E5%BD%B0)《印度佛教史》，或[吕澂](https://zh.wikipedia.org/wiki/%E5%91%82%E6%BE%82)《印度佛学源流略讲》。历史。
- 西方哲学与认知科学中与无我论证平行的工作：Derek Parfit [*Reasons and Persons*](https://en.wikipedia.org/wiki/Reasons_and_Persons) 第三部分，Thomas Metzinger [*The Ego Tunnel*](https://www.basicbooks.com/titles/thomas-metzinger/the-ego-tunnel/9780465020690/)，Anil Seth [*Being You*](https://www.anilseth.com/being-you/)。三者分别从人格同一性、自我模型、预测加工出发，得出与五蕴分析相近的结论。
- 如果对"心构造世界"这一线索有兴趣，可读唯识，《唯识三十颂》配一本讲记。

**不建议的起点。** 藏传密续与上师圈子，入门条件高，华语市场中假冒上师和收费传法的情况较多。以禅为名的通俗心灵读物。承诺短期开悟或按课程收费传法的体系。

## 练习入门

安那般那念，即观呼吸，是佛陀推荐的起点，各传承通用。以下是最简做法。

**姿势。** 椅子或坐垫均可，脊柱直而不僵，不靠背，手放腿上，眼睛微闭或垂视。膝盖疼痛就调整姿势，不必忍耐。

**对象。** 把注意力放在呼吸的感觉上，鼻端的气流或腹部的起伏，选定一处不再更换。不控制呼吸。

**走神。** 走神是常态。注意到走神后回到呼吸，不加评判。回来的这个动作就是练习本身，练习不是持续的专注，而是反复的回来。走神多少次就回来多少次，这一坐并没有失败。

**时长。** 每天二十到三十分钟，固定时间，使用计时器。每天二十分钟好于周末两小时。最初几个月只做这一件事。

**状态。** 平静、喜悦、光、身体感消失，这些迟早会出现。出现时观察它，不追求也不抓取。追求状态是各传承都提醒的常见偏差。

**几周之后。** 可以加入标记，即走神时在心中命名：想、听、痛。或加入身体扫描。此时可以读一本练习手册：[德宝法师](https://en.wikipedia.org/wiki/Henepola_Gunaratana)《观呼吸》是常被推荐的入门手册；坦尼沙罗比丘 [*With Each and Every Breath*](https://www.dhammatalks.org/books/WithEachAndEveryBreath/Section0001.html) 可免费阅读；[马哈希](https://www.accesstoinsight.org/lib/authors/mahasi/)的著作是标记法的来源，其 [*The Progress of Insight*](https://www.accesstoinsight.org/lib/authors/mahasi/progress.html) 是阶段地图的来源；[Culadasa](https://books.google.com/books?vid=ISBN9781501156984) *The Mind Illuminated* 是结构最系统的止禅手册，分十个阶段。作者 2019 年因个人操守问题被其教学组织解除职务，书的内容可以独立评价。

**密集禅修。** 有几个月日常基础后，可以考虑第一次密集禅修。华语世界最容易参加的是[葛印卡系统的十日内观课程](https://www.dhamma.org/zh/)，免费、非宗派，各地有中心。[法鼓山](https://www.ddm.org.tw/)有初级禅训班和禅七。泰国、缅甸、斯里兰卡有接受外国人的道场。没有日常基础直接参加十日课程，对一部分人有不良反应的风险。

**老师。** 到某个阶段需要老师，因为路上有几处一个人很难判断：把某个阶段的喜悦误认为开悟，以及随后的低谷。选老师看日常行为，不看宣称。涉及金钱、性、神秘化、自称证量、不欢迎提问，出现任何一条都应离开。

**不良反应。** 确实存在。长时间密集练习可能引发焦虑、人格解体、失眠加重、创伤记忆重现。出现后应停止，寻求有经验的老师，必要时就医。Brown 大学 Willoughby Britton 的团队专门研究这一问题，[Cheetah House](https://www.cheetahhouse.org/) 是他们建立的支持资源。

## 常见偏差

- 空病，或灵性逃避。以"无我""皆空"为由回避应当处理的事。空否定的是独立实体，不否定责任。
- 追求状态。把某种平静或喜悦当作目标。
- 把地图当作评分。阶段地图有用，用来给自己评分有害。
- 生灭阶段的误认。练习到某一阶段会出现光明、喜悦、清晰、信心，传统列有十种观染，提醒此时最容易误认为开悟。其后往往是一段低谷，也是路的一部分。
- 把当下变成新的身份。观察者、临在、觉知，任何一个成为可以安住的对象，自我就以新的名义回来了。
- 只读不练，或只练不读。前者得到一套哲学，后者没有地图。
- 依赖上师。传承的意义是保证方法不走样，不是交出判断。
- 用佛学处理它不适合处理的问题。抑郁、焦虑障碍、慢性疼痛、创伤，应先就医。正念疗法有临床证据，但那是从佛教提取的技术，去掉了原有框架，并且有适应症。
- 把佛教当作科学。它是关于苦和自我的现象学与训练，宇宙论是它的预设。
- 把修行当作项目管理。修行的进展没有可预设的里程碑。

## 常见问题

**需要相信轮回吗。** 不需要先相信。早期文本预设轮回，离苦的动机框架建立在它之上，可以先搁置，但应知道自己在读一个动机框架与自己不同的文本。练习本身不依赖它。

**需要吃素吗。** 在家人没有要求。早期僧团托钵，不见、不闻、不疑为己而杀的肉可以食用。汉传僧人的全面素食是六世纪以后的事。

**需要皈依吗。** 皈依是正式表明以佛法僧为方向，不是入会。读和练都不以它为前提，是否皈依可以之后再决定。

**需要去寺庙吗。** 不需要。找老师和共修需要一个场所，可能是寺庙，也可能是禅修中心或私人聚会。

**无神论者可以学吗。** 可以。佛教不预设造物主，其体系中的天神也是轮回中的众生，与解脱无关。

**与心理治疗的关系。** 互补，不替代。正念减压和正念认知疗法是从佛教提取的技术，有临床证据。有诊断的心理问题应先就医，稳定后再练。

**与[《当下的力量》](https://en.wikipedia.org/wiki/The_Power_of_Now)一类书的关系。** 托利讲的是带有吠檀多和禅色彩的临在教学的通俗版本，方向大体一致。"观察思考者"对应自我模型变得可见，"痛苦之身"对应第二支箭。它的不足是只有对目标状态的描述，没有方法、阶段地图、偏差警告和共修。

**与道教、儒家的关系。** 三者在中国互相渗透了一千多年。禅宗的语言受道家影响很深，宋明理学则吸收了佛教的心性论。读禅宗语录时遇到自然、无为等词，应知道那是融合后的用法。

**多久见效。** 注意力的变化几周内可以察觉。深层的变化以年计，没有时间表。

**佛教、佛学、学佛的区别。** 佛教是宗教与制度，佛学是对它的研究，学佛是练习。本指引三者都涉及，重点在后两者。

## 术语表

- 佛。觉醒者，称号。
- 法。佛陀的教法；也指一切现象。
- 僧。修行者的团体，狭义指出家众。
- 苦，dukkha。不满足、不安稳、不可靠。
- 无常。一切有条件的事物都在变化。
- 无我。任何事物中都找不到独立、恒常的核心，包括自我。
- 空。无自性，任何事物都不能脱离条件独立存在。不是虚无。
- 缘起。此有故彼有，一切都是条件的产物。
- 涅槃。贪嗔痴的熄灭。不是死亡，不是天堂，不是虚无。
- 阿罗汉。上座部体系中完成修行道路的人。
- 菩萨。大乘体系中以成佛为目标、同时利益众生的修行者。
- 止。使心稳定、专注的练习。
- 观。看清现象的练习，内观是其系统化的形式。
- 禅那，jhāna。止禅中的深度专注状态，分若干层次。
- 正念，sati。记得把注意力放在当下发生的事上。现代用法已经泛化。
- 业。行为，特别是有意图的行为，及其后果。不是命运。
- 轮回。生死的循环，早期佛教的预设。
- 方便。教法按听者的根器调整。
- 戒定慧。三学，八正道的三组。
- 三皈依。皈依佛、法、僧。
- 五戒。不杀生、不偷盗、不邪淫、不妄语、不饮酒。
- 公案。禅宗用于参究的问答或故事。
- 经忏。有偿的法事与超度，明清以后寺院的经济基础。
